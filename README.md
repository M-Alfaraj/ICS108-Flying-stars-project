# ICS108-Flying-stars-project
Flying star is a  JavaFX OOP game where 10-sided colored stars spawn from the center, grow, and move outward. The player controls a colored circle with the mouse and must hit matching-colored edges to score points. Wrong matches lose a life. The game ends when all attempts are used. 

## Gameplay
- Star-shaped polygons spawn from the center and grow as they move outward.
- Each edge has a random color.
- The player controls a colored circle using the mouse.
- Match the circle color with a star edge to score points.
- Wrong match = lose a life.
- Game ends when all attempts are used.

## Features
- Real-time animation using JavaFX
- Mouse-based player control
- Randomized star colors
- Score tracking (success rate)
- Average reaction time display
- Invulnerability Shield effect to project against wrong matches

## Technologies
- Java
- JavaFX
- OOP principles

## How to Run
1. Clone the repository
2. Open in IntelliJ (with JDK 21 + JavaFX support)
3. Run the main JavaFX application class
